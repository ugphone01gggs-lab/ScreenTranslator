# Screen Translator (Android, Kotlin)

ปุ่มลอยแปลข้อความบนหน้าจอ (ญี่ปุ่น / เกาหลี / อังกฤษ → ไทย) ทำงานในเครื่องด้วย ML Kit

## วิธีใช้
1. push โฟลเดอร์นี้ขึ้น GitHub (ทั้ง `settings.gradle.kts`, `app/`, `.github/`)
2. ไปที่แท็บ Actions ดาวน์โหลด `screen-translator-apk` แล้วติดตั้ง
3. เปิดแอป เลือกภาษา → อนุญาต "แสดงทับแอปอื่น" → กด "เริ่มปุ่มลอยแปลภาษา" → อนุญาตจับภาพหน้าจอ
4. เปิดมังงะ แล้วกดปุ่ม "แปล" สีน้ำเงินที่ลอยอยู่ คำแปลจะขึ้นทับตำแหน่งเดิม กดอีกครั้งเพื่อซ่อน

## หมายเหตุ
- ครั้งแรกจะดาวน์โหลดโมเดล OCR และโมเดลแปล (ต้องมีเน็ต)
- ชื่อแพ็กเกจคือ `com.example.screentranslator` เปลี่ยนได้ที่ `app/build.gradle.kts` และโฟลเดอร์ `java/`
- แอปที่ป้องกันการแคปหน้าจอ (FLAG_SECURE) จะจับภาพไม่ได้
